# 부스 사진

OFF THE RECORD 부스(지스타)에서 방문객이 게임 캐릭터와 함께 찍는 사진 앱. 2026-11-11 작성.

## 무엇

- **하는 일** — 카메라 화면에 캐릭터 둘(흰 머리 우주인, 아리아)을 세워 함께 찍는다. 바닥 그림자, 장면 빛에 맞춘 색, 카메라만큼 무른 선과 입자감, 사람이 앞에 서면 캐릭터를 가리는 처리로 붙인 스티커가 아니라 옆에 서 있는 사진처럼 보이게 한다.
- **두 모드, 한 앱** — 부스 모드(`?booth=1`)는 삼각대에 세운 노트북·태블릿을 직원이 다루는 가로 화면. 폰 모드(주소 옵션 없음)는 방문객이 자기 폰으로 여는 세로 화면.
- **진짜 AR(WebXR)이 아닌 이유** — iOS Safari에 WebXR AR이 없고, 2D 그림을 3D 공간에 세우면 판지처럼 보이고, 방문객은 앱을 깔지 않는다. 그래서 카메라 화면 합성으로 만든다.
- **설치 없음** — 빌드 없는 웹 페이지(ES 모듈, 캔버스 2D). Node는 로컬 서버와 시험에만 쓴다.

## 부스에서 켜는 법

- **노트북 + 웹캠** — 이 폴더에서 처음 한 번 `npm install`, `npm run 받기`. 그다음부터 `npm run 시작` → 크롬에서 `http://localhost:8770/?booth=1` → `F`로 전체 화면. 포트를 바꾸려면 `npm run 시작 -- --port 8771`.
- **처음 배치** — 처음에는 배치가 풀려 있다. 캐릭터를 눌러 고르면 점선과 크기 손잡이가 나온다. 바닥의 발 자리 표시에 발을 맞추고 크기를 맞춘 뒤 `L`로 잠근다. 잠그면 방문객이 캐릭터를 움직일 수 없다. 잠금은 가로·세로 화면에 같이 걸린다.
- **배치는 장면에 붙어 있음** — 전체 화면이 풀리거나 창 크기가 바뀌어 화면 비율이 달라져도 캐릭터 발은 카메라 영상의 같은 자리(바닥 표시)에 남는다. 다음에 다른 창 크기로 열어도 마찬가지다. 그래도 맞추기는 실제로 쓸 화면(전체 화면)에서 한다.
- **태블릿** — 태블릿 브라우저는 https 주소에서만 카메라가 켜진다. 호스팅 주소가 정해지면 그 주소 뒤에 `?booth=1`을 붙여 연다(미정). 키보드가 없으면 왼쪽 위 OFF THE RECORD를 2초 누르면 설정이 열리고, 설정의 배치 칸에서 배치 잠금·풀기를 한다. iPad는 자동 잠금을 끄고, 앞 카메라를 쓰면 센터 스테이지도 끈다(켜져 있으면 화면이 저절로 움직여 바닥 표시와 어긋난다).
- **QR** — `?booth=1&qr=<폰 모드 주소>`를 붙이면 라이브 화면 오른쪽 위에 QR이 뜬다. QR 생성기를 못 불러오면 QR 없이 돈다.
- **인쇄** — 셀피 프린터를 윈도 기본 프린터로 두고, 드라이버 기본값을 엽서(100×148mm)·여백 없음으로 둔다. 크롬 인쇄 미리보기에서 여백은 없음. 한 장에 약 41초. 크롬을 `--kiosk --kiosk-printing`으로 켜면 대화상자 없이 기본 프린터로 바로 인쇄되지만 공식 지원 기능이 아니라 부스 노트북에서 먼저 시험해야 한다. iPad 사파리 18.2 미만은 앱이 정한 용지 크기(4×6인치)를 무시하므로 인쇄 시트에서 용지를 고른다(실기기 미확인).
- **화면 꺼짐** — 부스 모드는 화면 꺼짐 막기를 켠다(첫 탭·키 뒤부터). 노트북 절전 설정도 꺼 둔다.
- **카메라가 멈추면** — 미리보기 영상이 4초 넘게 멈추면(웹캠 케이블 흔들림, iPad를 잠갔다 켬) 카메라를 저절로 다시 연다.

## 폰 모드

- **주소** — https 주소가 필요하다. 같은 와이파이에서 노트북 IP를 http로 열면 카메라가 켜지지 않는다. 호스팅 주소는 미정.
- **화면** — 사진은 위, 조작 단추는 아래 검은 띠(폰을 가로로 돌리면 오른쪽 띠)에 있다. 보이는 사진 영역이 그대로 찍히고, 발과 발밑 그림자가 단추에 가리지 않는다.
- **조작** — 셔터, 앞뒤 카메라 바꾸기, 캐릭터 끌어 옮기기·두 손가락으로 크기, 옆에 세우기, 셔터 왼쪽 틀 이름을 누르면 틀이 바뀐다. 결과 화면의 저장은 공유 시트(사진 앱에 저장 포함)를 열고, 공유가 안 되는 브라우저에서는 내려받는다. 사진을 길게 눌러도 저장된다.
- **사람 인식 모델** — 폰은 데이터 요금을 생각해 작은 모델(약 250KB)만 받는다.

## 오프라인 준비

- **받기** — `npm run 받기`가 `./라이브러리/`에 약 32MB를 받는다. MediaPipe 1.2.2(wasm 포함), 사람 분할 모델 셋, QR 생성기 2.0.4. 이미 있는 파일은 건너뛰고, 다시 받으려면 `npm run 받기 -- --force`.
- **없으면** — `./라이브러리/`가 없으면 CDN에서 받는다. 인터넷도 없으면 사람 인식 없이 돈다(가림·옆에 세우기만 빠진다).
- **글꼴** — 구글 폰트(IBM Plex Sans KR, IBM Plex Mono)에서 받는다. 인터넷이 없으면 시스템 글꼴로 그린다.
- **브라우저 조건** — MediaPipe 1.2.2는 Safari 16.4 이상, 크롬 91 이상이 필요하다.

## 직원 조작

- **Space / Enter** — 촬영. 결과 화면에서는 다시 찍기. 마우스·손가락으로 단추를 누른 뒤에도 그대로다(발판·리모컨용). Tab으로 단추를 골라 초점 테두리가 보일 때만 그 단추를 누른다.
- **F** — 전체 화면.
- **S** — 설정 열고 닫기.
- **L** — 배치 잠금·풀기. 글자 단축키는 한글 입력 상태여도 된다.
- **Esc** — 설정 닫기, 카운트다운 취소, 결과 화면에서 돌아가기. 전체 화면에서는 Esc가 전체 화면도 풀어 버리므로 결과 화면에서 돌아갈 때는 Space/Enter를 쓴다.
- **배치를 풀었을 때** — 캐릭터를 끌어 옮기기, 오른쪽 위 손잡이나 휠로 크기, Tab으로 캐릭터 고르기, 화살표로 조금씩 옮기기(Shift는 크게), `+` `-`로 크기. 화면 위 가운데 단추로 옆에 세우기, 좌우 반전, 사람이 앞 / 캐릭터가 앞, 배치 잠금.
- **캐릭터 고르기** — 왼쪽 아래 얼굴 단추(둘 다 / 하나만). 배치를 푼 상태에서 고르면 그게 부스 기본값이 되고, 잠긴 상태에서 방문객이 고른 것은 처음 화면으로 돌아가면 기본값으로 돌아간다.
- **결과 화면** — 틀 고르기, 저장(부스 노트북의 내려받기 폴더에 쌓인다), 인쇄, 다시 찍기. 아무도 안 만지면 정한 시간(기본 60초) 뒤 처음 화면으로.

## 설정

- **카메라** — 카메라 고르기, 해상도(1080p / 4K), 거울 반전(자동은 앞 카메라·웹캠만 거울).
- **촬영** — 카운트다운 3·5·10초, 기본 틀, 처음 화면으로 돌아가는 시간(부스), 소리.
- **사진처럼 보이기** — 색 맞춤 세기(기본: 부스 0.6, 폰 0.35. 폰에서 세게 맞추면 옆 인쇄 포스터보다 바래 보였다), 그림자 세기, 입자감, 사람이 앞에 서면 캐릭터 가리기, 옆에 세우기 키 비율(사람 키 = 1).
- **색 맞춤이 하는 일** — 화면 전체의 어두운 쪽·밝은 쪽에 맞춰 캐릭터의 검정과 흰색을 맞춘다(어두운 방에서 캐릭터만 빛나지 않게). 캐릭터 둘레 빛의 색을 조금 옮기고, 그림 색을 조금 뺀다(부스 기본 0.85배, 폰 기본 약 0.91배). 세기를 1로 올리면 더 세게 맞춘다.
- **사진 글자** — 제목(기본 OFF THE RECORD), 부제(기본 삼유스튜디오).
- **배치** — 배치 잠금·풀기(부스), 배치 처음대로(지금 방향만, 잠금은 그대로), 전체 화면.
- **저장 위치** — 브라우저 저장소에 부스·폰 따로 저장한다. 바꾼 값은 0.3초 뒤에 저장하고, 탭을 닫거나 숨길 때는 바로 저장한다. 사생활 창처럼 저장이 막히면 매번 기본값으로 시작한다.

## 촬영 환경 체크리스트

- **조명** — 정면에서 고르게. 한쪽만 밝으면 캐릭터와 사람의 빛이 어긋난다.
- **배경** — 단색 벽이나 천. 사람 인식이 깔끔해진다.
- **바닥 표시** — 캐릭터 발 자리를 바닥에 테이프로 표시해 두고 그 자리에 배치를 맞춘다. 방문객이 설 자리도 표시한다.
- **카메라** — 높이 1.2~1.4m, 약 2.5m 거리에서 발까지 다 들어오게.
- **세로 모니터** — 세로로 세운 화면이면 두 사람 전신이 더 잘 들어간다(웹캠도 돌려 단다).

## 캐릭터 그림 바꾸기

- **파일만 바꿀 때** — `캐릭터/` 안의 PNG(배경 투명)를 같은 이름으로 덮어쓰고, 그림 속 위치가 달라졌으면 `캐릭터/캐릭터.json` 값을 고친다.
- **캐릭터.json 칸** — 값은 모두 PNG 크기 기준 0~1 비율.
  - `id` — 내부 이름(`record`, `aria`). 배치 저장에 쓰므로 바꾸면 그 캐릭터 배치가 처음대로 돌아간다.
  - `name` — 화면 읽기용 이름(aria-label). 화면에 글자로는 안 나온다.
  - `file` — PNG 파일 이름.
  - `top` — 머리 꼭대기 높이.
  - `feet.x`, `feet.y` — 발 지점(두 발 가운데, 발바닥 맨 아래). 머리~발 높이가 키다.
  - `face.x`, `face.y`, `face.size` — 얼굴 썸네일 정사각형의 가운데와 한 변(PNG 폭 비율).
- **개수** — 몇 개든 된다. 정확히 둘이면 둘 다 / 하나만 단추, 그 밖에는 캐릭터마다 켜고 끄는 단추가 나온다.

## 확인 방법

- **단위 시험** — `npm run 시험`. 순수 모듈(화면 변환, 배치, 색 맞춤, 틀, 설정, 파일 이름, 마스크 처리)을 노드로 시험한다.
- **전체 확인** — `npm run 받기` 뒤 `npm run 확인`. 헤드리스 크롬에 가짜 카메라 장면 둘(밝은 벽, 어둡고 따뜻한 조명)을 넣고 부스·폰 화면에서 라이브 → 촬영 → 틀 셋 → 저장 파일, 부스는 캐릭터 고르기 셋까지 찍어 `./출력/`에 둔다. 캐릭터 고르기·끌어 옮기기·설정창, 옆에 세우기 발 높이, CDN 경로(`?cdn=1`)도 확인한다. 콘솔 오류가 하나라도 있으면 실패. 사람 대역은 `시험/사람실루엣.png`(목업의 검은 실루엣에서 뽑음, `시험/실루엣.py`).
- **되돌이 확인** — 밝은 벽 부스 화면에서 고쳤던 문제도 다시 본다. 얼굴 칩·저장을 마우스로 누른 뒤 Space가 촬영·다시 찍기로 가는지, 저장 알림이 결과 화면 위에 보이는지, 결과를 그리는 사이에 돌아가도 대기 타이머가 새지 않는지, 결과 화면에서 해상도를 바꾸면 결과가 닫히는지, 창 비율이 바뀌어도 발 자리가 영상에서 1px 안에 남는지, 가로에서 잠그고 세로로 돌려도 잠긴 채인지.
- **GPU 없이** — `npm run 확인 -- --no-gpu`면 소프트웨어 그래픽(SwiftShader)을 강제로 켜서 가벼운 모델로 내려가는 길을 확인한다. 실제로 GPU가 막힌 노트북에서는 브라우저가 소프트웨어 그래픽을 안 켜 줄 수 있어서, 그때는 사람 인식 없이 진행으로 내려간다(앱은 그대로 돈다).

## 주소 옵션

- **`?booth=1`** — 부스 모드.
- **`?debug=1`** — fps, 사람 인식 모델·시간, 장면 통계, 색 맞춤 값, 사람 마스크(붉은 덮개)를 보여 준다. 사진에는 안 들어간다.
- **`?qr=<주소>`** — 부스 QR.
- **`?cdn=1`** — `./라이브러리/`를 건너뛰고 CDN에서 받는다.
- **`?model=multiclass|selfie|landscape`** — 사람 인식 모델 강제.

## 사진은 기기 밖으로 나가지 않음

- **업로드 없음** — 사진은 그 기기 안에서 만들고, 저장·공유·인쇄도 그 기기에서 한다. 서버로 보내지 않는다.
- **외부 요청** — 구글 폰트, 그리고 `./라이브러리/`가 없을 때의 CDN만 받는다. MediaPipe가 보내는 사용 통계(사진은 아님)는 앱이 막는다.

## 미정

- 사진 전달 방식(인쇄 · 방문객 폰 QR · 둘 다)
- 틀 선택(그대로 · 인화지 · 기록 밖)
- 두 캐릭터의 실제 키 비율(지금은 같은 키)
- 흰 머리 캐릭터 이름 표기
- 더 큰 캐릭터 원본(지금은 시트 정면 그림 약 700px을 2배로 키움)
- 호스팅 주소
- 행사 문구
- 아리아(청록 머리)와 금 레코드가 한 화면에 나옴: 무드보드 규칙(금·청록 한 화면 금지)과 부딪친다. UI·틀에는 청록·금색을 쓰지 않았다
- 가로 인화지 비율: 지금 약 1.2:1(사진 3:2 + 아래 여백 18%)이라 6×4 용지에 찍으면 좌우에 흰 여백이 남는다
